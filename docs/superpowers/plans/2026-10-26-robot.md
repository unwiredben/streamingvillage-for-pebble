# Strolling robot implementation plan

**Goal:** Add the approved purple/blue robot behind the city during occasional animation runs.

**Design:** Draw a roughly 48 × 138 reference-pixel robot with purple armour, blue panels and cyan eyes, between the mountains and foreground. Scale geometry using the existing Emery reference macros. Swing arms and legs and bob the body as it crosses left to right, opposite the scrolling city (updated per user feedback). Select one in three fresh runs; repeated taps during a run must not respawn it. Use only the existing frame timer, stop drawing at run completion or focus loss, and preserve billboard timing.

**Architecture:** `src/c/robot.h` and `robot.c` own state, movement and drawing. `main.c` chooses fresh appearances, advances state and draws in scene order. Existing host tests exercise the real module across all four platforms.

**Validation:** Build Basalt, Chalk, Emery and Gabbro with SDK 4.33.1, run host and artwork regression checks, then capture actual emulator frames and a robot animation preview. No additional bitmap resources or dynamic allocations.

- [x] Implement the robot module and wire it into the existing animation lifecycle and draw order.
