# Hovering UFO implementation plan

**Goal:** Add the approved silver-blue saucer with a cyan dome and blinking rim lights, mutually exclusive with the robot.

**Design:** Each fresh run makes one equal-probability choice: robot, UFO, or empty skyline. The UFO glides left to right above the rooftops, pauses at the center for two seconds while bobbing, then exits before the run ends. Taps during a run preserve the selection and visitor position. Both visitors disappear on focus loss and animation completion.

**Architecture:** Add `src/c/ufo.h` and `ufo.c` with fixed-size state, frame advancement and primitive drawing, following the robot module. `main.c` owns selection, advances both states with the existing timer, draws the UFO between mountains and foreground, and clears both on stop. No additional allocations, resources or timers.
